About This Spelling Bee Word Finder

Enter six outer letters and a required center letter to find possible English words made only from those letters. Every displayed word contains the center letter and has at least four characters.

Words that use all seven available letters are marked as pangrams. Dictionary acceptance rules vary by puzzle, so this tool is best used as a word-finding aid rather than an exact replica of a particular puzzle’s official word list.

How to Use This Spelling Bee Solver

Enter the required center letter in the yellow honeycomb cell, then add the six outer letters in any order. Select Find Words to generate possible English words that use only your seven letters, include the center letter, and contain at least four characters.

Find Pangrams and Longer Words

Results are grouped by word length so you can explore longer possibilities first. A crown icon marks a possible pangram: a word that uses each of the seven available letters at least once. The displayed point total uses the common Spelling Bee-style convention of one point for four-letter words, one point per letter for longer words, and a seven-point pangram bonus. This tool uses a general English dictionary, so results can differ from an official publisher word list.
